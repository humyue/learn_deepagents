# 0002 — 教学站已建成：40 课 + 4 份速查手册，覆盖官方全部 35 个页面

- **日期**：2026-10-08（会话 1）
- **状态**：已交付，待用户实际学习后修订

## 背景

用户要求把 Deep Agents 官方文档左侧导航的全部章节"总结成一个新的教学网站"。
在 0001 号记录里已确认：动机是理解 harness 原理、语言为中文+英文术语、无 API Key、需要全覆盖。

## 决定

1. **课程结构不用官方导航，改用 harness 解剖结构**：
   心智模型 → 执行环境 → 上下文工程 → 委派 → 运行时管控 → 流式与前端 → 应用与生产。
   官方 35 个页面被拆成 **40 课**（有几页被拆开，例如 overview 拆成心智模型+全景解剖，
   backends 拆成"虚拟文件系统"与"六个 backend 取舍"）。

   理由：官方导航按"功能页"组织，适合查阅；教学需要按"依赖顺序"组织，适合理解。
   例如必须先讲清"虚拟文件系统是地基"（第 06 课），后面的 offloading / skills / memory
   才有落点。

2. **Tier A / Tier B 分层**：原理核心章节（14 课）做完整拆解
   （动机 → 机制 → 代码 → 坑 → 自测）；集成/教程类章节做精炼但完整（定位 → 机制要点 → 关键 API → 自测）。
   目的是在"覆盖 35 页"和"讲透原理"之间取得平衡。

3. **练习形式改为检索式自测**：因为用户没有 API Key，无法用"跑通就懂了"作为反馈回路。
   改成每课 2–4 道 retrieval 题（138 题总数），答完立即给解析。
   这反而更利于 storage strength。

4. **提示框、流程图、栈图全部自建组件**：不依赖 mermaid/CDN，
   保证 `file://` 直接打开可读、可打印（`@media print` 已适配）。

## 工程决策

| 决策 | 理由 |
| - | - |
| 纯静态 HTML + 内容源与产物分离（`content/*.md` → `build.py` → `lessons/*.html`） | 改内容只改 markdown，不手改生成的 HTML |
| 共享 `assets/styles.css` + `assets/course.js` | 40 课风格统一；进度/自测逻辑只写一份 |
| 进度存 localStorage | 无需后端，离线可用 |
| 用 Python + `markdown` + `pygments` 生成 | 表格、代码高亮、admonition 开箱即用 |
| 保留 `raw/*.md` 官方原文快照 | 所有课程断言都能回溯核对 |

## 遇到的坑（值得记住）

1. **HTML 里的 `>` 必须写成 `&gt;`**。在流程图节点文本里写 `> 20,000 token`
   会生成非法 HTML。已修复两处（第 15 课、选型图）。
2. **slug 必须全局唯一**。它同时是文件名、导航锚点、localStorage 进度键。
   第 04 课与中间件速查手册曾撞名 `middleware-stack`，导致进度互相污染。
   已在 `build.py` 里加了构建期冲突检测。
3. **bash heredoc 写中文 markdown 不可靠**（出现过定界符不匹配导致内容泄漏进文件）。
   改用文件写入工具逐个创建，更稳。
